Please note that Google Play can reject your app if the use case is not strictly required.
You can find acceptable use cases for permission REQUEST_IGNORE_BATTERY_OPTIMIZATIONS on Android here, according to Android developers.
Please note that if you are using a feature that requires location services & disable it here, these features will not work correctly.
Google Play only accepts these permissions for apps whose core purpose is photo or video access, and rejects the others. Picking a photo with the system photo picker keeps working without them.
